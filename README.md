# מחשבון מעשר 🪙

אפליקציה לחישוב מעשר (או חומש) שמושכת את התנועות **אוטומטית מהבנקים ומחברות האשראי בישראל**,
מזהה הכנסות ותרומות, ומראה כמה נשאר לתת.

## מה היא עושה

- **משיכת נתונים אוטומטית** מהבנקים ומחברות האשראי (בעזרת הספרייה הפתוחה
  [israeli-bank-scrapers](https://github.com/eshaham/israeli-bank-scrapers)):
  - בנקים: הפועלים, לאומי, דיסקונט, מזרחי טפחות, מרכנתיל, הבינלאומי, אוצר החייל, מסד, פאג"י, איגוד, יהב
  - כרטיסי אשראי: מקס, כאל, ישראכרט, אמריקן אקספרס, ביחד בשבילך, בהצדעה
- **סיווג אוטומטי**: זיכוי בחשבון הבנק = הכנסה; חיוב שמכיל "תרומה"/"צדקה"/"גמ"ח" = תרומה;
  העברות בין חשבונות, פיקדונות והלוואות = לא נספרים.
- **כללי סיווג** שאפשר לערוך (למשל: כל תנועה עם "ישיבת..." היא תרומה), ו**שינוי ידני** של סיווג כל תנועה.
- **הוספה ידנית** של הכנסות או תרומות במזומן.
- **סיכום**: סך הכנסות, מעשר לתשלום, כמה נתרם, יתרה – וגם פירוט לפי חודשים עם יתרה מצטברת.
- הגדרות: 10% או 20%, תאריך התחלה, יתרת פתיחה, סנכרון אוטומטי כל X שעות.

## אבטחה ופרטיות

- הכל רץ **על המחשב שלך בלבד**. השרת מאזין רק ל-`127.0.0.1` כברירת מחדל.
- פרטי ההתחברות לבנקים **מוצפנים** (AES-256-GCM) עם מפתח שנגזר מ**סיסמת-על** שאתם בוחרים.
  סיסמת-העל לא נשמרת בשום מקום. אם שוכחים אותה, צריך להזין את פרטי הבנקים מחדש.
- הנתונים נשמרים בקובץ `data/db.json` (לא נכנס ל-git).
- מומלץ, אם הבנק מאפשר, ליצור משתמש "צפייה בלבד" לאתר הבנק.

## התקנה והרצה

צריך [Node.js](https://nodejs.org) בגרסה 22.22 ומעלה.

```bash
npm install
npm start
```

ואז לפתוח בדפדפן: http://127.0.0.1:3000

1. בוחרים סיסמת-על.
2. בלשונית **חשבונות** מוסיפים בנק או כרטיס אשראי.
3. לוחצים **סנכרון מהבנקים** (הסנכרון הראשון לוקח דקה-שתיים: פותחים דפדפן ברקע ומתחברים לאתר הבנק).
4. עוברים על לשונית **תנועות** ומתקנים סיווגים לפי הצורך (למשל החזר הוצאות מהעבודה = "לא נספר").

## סנכרון מתוזמן (לא חובה)

אפשר להגדיר באפליקציה "סנכרון אוטומטי כל X שעות" (פועל כל עוד האפליקציה פתוחה ולא נעולה),
או להריץ סנכרון משורת הפקודה, למשל מ-cron:

```bash
MAASER_MASTER_PASSWORD='הסיסמה שלך' npm run sync
```

## משתני סביבה

| משתנה | תיאור |
|---|---|
| `PORT` | פורט (ברירת מחדל 3000) |
| `HOST` | כתובת האזנה (ברירת מחדל `127.0.0.1`) |
| `MAASER_DATA_DIR` | תיקיית הנתונים (ברירת מחדל `./data`) |
| `MAASER_MASTER_PASSWORD` | פתיחה אוטומטית בהפעלה (למשל בשרת ביתי) |
| `CHROME_PATH` | נתיב לכרום/כרומיום קיים במקום זה שמותקן אוטומטית |
| `MAASER_SHOW_BROWSER=1` | להציג את הדפדפן בזמן הסנכרון (לבדיקת תקלות) |
| `MAASER_NO_SANDBOX=1` | להריץ את הדפדפן בלי sandbox (נדרש לפעמים ב-Docker/לינוקס כ-root) |

## הערות

- רוב הבנקים מאפשרים למשוך היסטוריה של כשנה אחורה בלבד. להכנסות ישנות יותר אפשר להשתמש ב"יתרת פתיחה".
- אם בנק משנה את האתר שלו, הסנכרון עלול להישבר עד לעדכון הספרייה: `npm update israeli-bank-scrapers`.
- האפליקציה היא כלי עזר לחישוב. לשאלות הלכתיות (ברוטו/נטו, מה נחשב הכנסה, למי מותר לתת מכספי מעשר) כדאי להתייעץ עם רב.
