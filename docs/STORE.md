# פרסום בחנויות האפליקציות

האפליקציה בנויה כ-**PWA** (אפליקציית אינטרנט מתקדמת): יש לה manifest, אייקונים ו-service worker.
לכן:
- **כבר עכשיו** אפשר "להתקין" אותה מהדפדפן בטלפון (Chrome באנדרואיד: "הוספה למסך הבית" / "התקנה";
  Safari באייפון: שיתוף ← "הוסף למסך הבית").
- **Google Play**: עוטפים את האתר באפליקציית אנדרואיד מסוג TWA (Trusted Web Activity). אין צורך לכתוב קוד אנדרואיד.
- **App Store (אפל)**: אפשרי, אבל דורש מנוי מפתח של אפל ומחשב Mac (פירוט למטה).

## Google Play (תחת me321dev)

### 1. חשבון מפתח
1. היכנסו עם **me321dev** ל-https://play.google.com/console ופתחו חשבון מפתח (תשלום חד-פעמי של 25$).
2. חשבון פרטי חדש ב-Play צריך לעבור **בדיקה סגורה** (closed testing) עם לפחות 12 בודקים במשך 14 יום
   לפני שאפשר לפרסם לכולם. כדאי להתחיל מוקדם.

### 2. בניית קובץ האפליקציה (AAB)
הדרך הפשוטה: https://www.pwabuilder.com
1. מכניסים את כתובת האתר (למשל `https://maaser-me321.fly.dev`) ← **Package for stores** ← **Android**.
2. Package ID: למשל `dev.me321.maaser`. App name: מחשבון מעשר.
3. מורידים את הקובץ. בתוכו: `app-release-bundle.aab`, קובץ חתימה (`signing.keystore`) ו-`assetlinks.json`.
   **שמרו את קובץ החתימה ואת הסיסמה שלו במקום בטוח** – בלעדיהם אי אפשר לעדכן את האפליקציה.

(חלופה בשורת פקודה: `npx @bubblewrap/cli init --manifest https://<הכתובת>/manifest.webmanifest` ואז `bubblewrap build`.)

### 3. קישור האפליקציה לאתר (Digital Asset Links)
כדי שהאפליקציה תיפתח בלי שורת כתובת, האתר צריך לאשר אותה. השרת כבר מגיש את
`/.well-known/assetlinks.json` לפי משתני סביבה:

```bash
fly secrets set ANDROID_PACKAGE_NAME=dev.me321.maaser \
  ANDROID_CERT_SHA256="AA:BB:...:FF"
```
- את טביעת האצבע (SHA-256) לוקחים מ-`assetlinks.json` שהתקבל מ-PWABuilder.
- אחרי ההעלאה ל-Play, אם מפעילים **Play App Signing**, צריך להוסיף גם את טביעת האצבע של Google:
  Play Console ← האפליקציה ← **Setup** ← **App signing** ← "SHA-256 certificate fingerprint".
  אפשר לשים כמה ערכים, מופרדים בפסיק.
- בדיקה: `https://<הכתובת>/.well-known/assetlinks.json` צריך להחזיר את הנתונים.

### 4. מילוי פרטי האפליקציה ב-Play Console
- **מדיניות פרטיות**: `https://<הכתובת>/privacy.html` (קיים באפליקציה).
- **מחיקת חשבון**: Google דורשת דרך למחוק חשבון. קיים: הגדרות ← "מחיקת החשבון וכל הנתונים".
  בטופס Data safety מציינים את הכתובת של האפליקציה ואת ההוראות האלה.
- **Data safety**: נאסף מייל ושם (זיהוי), מידע פיננסי (תנועות בחשבון). מוצפן בהעברה. אפשר לבקש מחיקה. לא משותף עם צד שלישי.
- **קטגוריה**: Finance. שימו לב: לאפליקציות פיננסיות Google עשויה לבקש הצהרה נוספת (Financial features declaration).
  האפליקציה **לא** מציעה הלוואות, השקעות או תשלומים, רק קריאה וחישוב.
- צילומי מסך: לפחות 2 צילומי טלפון. אייקון 512×512 נמצא ב-`public/icons/icon-512.png`.

## App Store (אפל)
- דורש Apple Developer Program (99$ לשנה) ומחשב Mac עם Xcode.
- PWABuilder יכול לייצר גם פרויקט iOS, אבל אפל דוחה לא פעם אפליקציות שהן "רק אתר עטוף" (הנחיה 4.2).
- המלצה: להתחיל עם Google Play והתקנה כ-PWA באייפון. אם יהיה ביקוש, אפשר להוסיף לאפליקציית iOS יכולות מקומיות
  (למשל התראות על יתרת מעשר) כדי לעבור את הבדיקה.
